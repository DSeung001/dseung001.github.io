# 블로그 교정

이 스킬은 최대한 본문을 수정하지 않아.

프런트매터, H1 금지, series, Hugo 빌드는 저장소 루트 `AGENTS.md`를 따른다. 말투를 바꾸는 작업은 `blog-voice`가 담당한다. 이 스킬과 겹치면 교정만 하고 문장은 다시 쓰지 않는다.

## 고치는 것

- 오탈자. 예: `으제` → `위의`, `있었습디` → `있었습니다`, `꿈구는` → `꿈꾸는`, `영산편집` → `영상 편집`, `무언갈` → `무언가를`.
- 띄어쓰기. 의존 명사(`게`, `건`, `때`, `년`), `안`+용언, `-아/어 하다`, 보조 용언(`살아 오면서`, `기억해 두다`)은 띄어 쓴다. `수밖에`는 한 단어다.
- 이 블로그에 이미 쓴 외래어 표기가 있으면 그 표기로 맞춘다. 예: `서브컬쳐` → `서브컬처`, `콜렉터` → `컬렉터`. 처음 보는 표기는 그대로 둔다.
- 조사가 빠져 문장이 성립하지 않으면 그 조사만 넣는다. 예: `아래와 같다 생각했다` → `아래와 같다고 생각했다`.
- 사전에 없는 활용만 고친다. 예: `녹아져 있다` → `녹아 있다`, `열광되야` → `열광돼야`, `발달시켜` → `발전시켜`. 둘 다 말이 되면 원래 단어를 둔다.
- `이점`(장점)과 `이 점`(이 부분)은 문맥이 분명할 때만 가른다. 애매하면 붙여 쓴 형태를 유지한다.
- `<Br/>`, `<br>`, `<br />`는 `<br/>`로 통일한다. 줄 끝 공백은 지운다.

## 고치지 않는 것

- 어순, 말투, 문장 나누기, 더 나아 보이는 표현.
- 내용을 보태거나 빼는 일. 겹치는 말도 그대로 둔다.
- 없는 마침표를 채우는 일. 이미 있는 부호는 유지한다.
- 고유명사와 서비스 이름. `모두의 창업`과 `모두의창업`처럼 저자가 둘 다 썼으면 통일하지 않는다.
- 빈 줄의 개수. 예외는 아래 인용 규칙뿐이다.
- 프런트매터, 코드 펜스, 표, 머메이드, 수식.
- 이미지 경로와 HTML 속성. 이미지 alt의 명백한 오탈자만 고친다.

## `<br/>`

Goldmark는 빈 줄이 아닌 줄바꿈을 공백으로 합친다. 저자가 줄을 나눠 쓴 자리를 유지하려고 `<br/>`를 붙인다.

다음 줄이 같은 문단으로 이어지는 본문이면, 현재 줄 끝에 `<br/>`를 붙인다. 문장 부호 바로 뒤에 쓰고 앞에 공백을 넣지 않는다. 이미 있으면 또 붙이지 않는다.

붙이지 않는 줄:

- 묶음의 마지막 줄. 다음이 빈 줄이면 문단이 이미 나뉜다.
- 제목, 인용(`>`) 한 줄, 코드 펜스, 표, HTML 블록 안.
- 다음 줄이 새 목록 기호, 제목, 인용, 이미지(`![`), HTML 블록, 코드 펜스인 경우.
- 목록 항목이 한 줄씩 끝나고 다음 줄도 다음 번호인 경우.

인용 한 줄 바로 다음이 본문이면 그 사이에 빈 줄을 하나 넣는다. 빈 줄이 없으면 다음 문장이 인용 안으로 들어간다. 문장은 고치지 않는다.

목록 제목 줄 다음에 설명 문장이 빈 줄 없이 이어지면, 그 제목 줄 끝에만 붙인다.

```markdown
꽤나 많은 9개의 회사가 진행을 했습니다.<br/>
이를 하나씩 설명하는 건 위의 목표에 맞춰 정리하겠습니다.

1. 시장이 좁은 건 문제가 되지 않는다<br/>
바운드원은 좁은 시장이지만 전 세계를 타게팅해서 선점했습니다.
```

## 순서

1. 코드 펜스와 HTML 블록 구간을 표시해 두고 그 안은 건너뛴다.
2. 맞춤법과 띄어쓰기만 고친다.
3. `<br/>`를 붙이거나 표기를 `<br/>`로 맞춘다.
4. 바꾼 뒤 문장이 늘어나거나 말투가 바뀌지 않았는지 다시 읽는다.
